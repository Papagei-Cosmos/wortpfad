# 词间 Wortpfad 网页入口

此目录只包含 GitHub Pages 网页入口、应用清单和品牌图标。词库、试题、音频和账号服务通过独立的受保护服务提供，不在公开仓库中。

- 网页域名：`ci.wwwxqz.com`
- 账号与学习服务域名：`ci-api.wwwxqz.com`
- 学习记录继续保存在用户浏览器中，不上传进度或学习统计。

入口以内嵌应用的方式接入原有学习页面，保留其账号登录和全部学习功能。两个域名必须配置 HTTPS；后端只允许该自有前端域名嵌入。GitHub 默认域名不会直接嵌入后端，以避免跨站 Cookie 限制造成登录循环。

发布到公开仓库的根目录，启用 GitHub Pages，选择 `main` 分支和根目录 `/`。先在 Pages 设置绑定自定义域名，再按管理员提供的 DNS 说明添加解析。不要先设置一个尚未绑定仓库的 GitHub Pages CNAME。

这些文件不包含管理员初始化口令、账号密码、后台发布凭据或数据库文件。它们不应被加入仓库。

部署完成还需要分别测试大陆手机流量和宽带：GitHub Pages 或自定义域名本身都不能作为大陆可达性的保证。若账号服务无法直连，应更换后端托管环境；只替换前端地址不能解决该问题。

首次更换学习服务域名时，请先在旧网址导出本机学习记录，再从新网址恢复。本机浏览器存储按域名隔离，不能自动跨域迁移。
